The Operational Reality · Problem Statement

The Problem in the Client's Language

"Fifty-eight percent of tickets are some version of 'where is my order'. My agents copy and paste the same four replies all day. Average first response is nine hours." — Arpita, Head of Customer Experience (CX)

📊 Current Operational Bottlenecks:

  • Volume Crush: 9,000 support tickets arrive every week in informal Hinglish/English.
  • Repetitive Lookups: 5,220 tickets/week (~745/day) are spent repeatedly checking courier portals.
  • Manual Copy-Pasting: Agents manually copy from a shared Google Doc with 4 static canned replies.
  • Zero Tagging: Agents only categorize 'when they remember to', leaving Dhaga blind to trends.

💸 Labor & Headcount Cost:

  • 20 out of 34 Support Agents (FTEs) spend their entire day on canned lookups.
  • At ₹25,000/month fully loaded cost, Dhaga spends ₹5.0 Lakhs to ₹6.0 Lakhs every month just typing status updates.
  • ₹60 Lakhs – ₹72 Lakhs per year in wasted human capital.

Intentional Failure Mode · Production Resilience

What Broke That We Did Not Expect

The WhatsApp Phone Number Collision: How real-world user behavior forced a critical architectural safeguard.

❌ The Unexpected Failure Mode:

Over 35% of Tier-2/3 WhatsApp customers never mention their Order ID in opening messages (e.g. "Mera parcel nahi aaya refund do").

Repeat buyers frequently had two active concurrent orders in Postgres (e.g., an Anarkali Kurti shipped yesterday, and a Kidswear set processing today).

How It Broke: Early LLM prompts tried to guess the 'most relevant' order. The model guessed wrong 50% of the time, providing Delhivery tracking details for a Kurti when the customer was asking about the Kidswear set!

✅ The Deterministic Safeguard:

We implemented an explicit collision check in deterministic Python (lookup_order_details).

If customer phone returns > 1 active orders and no specific Order ID is in message text:

  • Emits AMBIGUOUS_ORDER_REFERENCE.
  • Strictly blocks unread automated dispatch.
  • Automatically formats a polite clarifying prompt: "Aapke number par 2 active orders hain (Kurti #DH-10520 & Boys Set #DH-10521). Kaunse order ke baare me jankari chahiye?"
  • Flags ticket in agent workbench with a visible warning pill.
